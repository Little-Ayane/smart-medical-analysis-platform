# 5 人详细任务清单

## P2 · 数据预处理与持久化工程师

| 阶段 | 任务 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 一期 | 大数据批量读取（分块读取 TSV/CSV，避免内存溢出） | `data_loader.py` | 200万条读取无卡顿/OOM |
| 一期 | 缺失值、异常值处理（如非新生儿 `Birth Weight` 置 N/A） | `data_cleaner.py` | 缺失率在合理范围 |
| 一期 | 数据去重（去除重复住院记录） | 去重逻辑 | 无重复主键记录 |
| 一期 | 数据类型标准化（`Total Charges` 去逗号转浮点、日期/编码标准化） | `data_standardizer.py` | 字段类型正确 |
| 一期 | 结构化批量入库 + 索引验证 | `data_loader_to_mysql.py` | 200万条成功入库、查询命中索引 |
| 二期 | 数据质量评估（完整性/准确性/一致性/时效性四维评分 + 可视化报告） | 质量评估模块、报告 | 报告可读、能定位异常 |
| 二期 | 数据备份与恢复（定时任务 + 手动备份） | 备份脚本 | 备份可恢复 |
| 二期 | 增量更新（识别新增与历史差异，避免重复入库） | 增量更新模块 | 增量正确、无重复 |

**验收口径**：数据入库后抽样 1 万条与原始文件对账，准确性 ≥ 99.9%，缺失率与业务规则一致。

## P3 · 大数据分析服务工程师

| 阶段 | 任务 | 交付物 | 验收标准 |
| --- | --- | --- | --- |
| 一期 | 多维度聚合分析（按疾病/年龄/医院/年份等，计算均值/占比/分布） | `aggregation.py` | 结果与 SQL 手算对账一致 |
| 一期 | 大数据算法封装（均值、占比、分布、异常识别） | `algorithms.py` | 算法结果准确 |
| 一期 | Flask RESTful API 开发（聚合接口、统一 JSON 信封） | `app.py` | 接口返回符合契约文档 |
| 一期 | 接入 MySQL 查询 + 查询优化（索引利用） | 查询层 | 查询耗时合理 |
| 二期 | 复杂分析（疾病关联、费用预测、再入院风险评估） | 机器学习模块 | 模型可运行、有评估指标 |
| 二期 | API 性能优化（Redis 缓存 + 查询优化 + 并发处理） | 缓存模块 | 高频查询命中缓存 |
| 二期 | 异常处理（异常捕获、参数校验、权限控制、友好提示） | 异常处理中间件 | 非法请求返回友好提示不崩溃 |

**验收口径**：与 P4 联调，AI 模块能正确调用 API 并取到结构化数据。
