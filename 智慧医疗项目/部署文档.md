## 二、Python 环境

### 2.1 安装 Python 3.11

```bash
sudo add-apt-repository -y ppa:deadsnakes/ppa
sudo apt update
sudo apt install -y python3.11 python3.11-venv python3.11-dev
python3.11 --version   # Python 3.11.15
```

### 2.2 创建虚拟环境并安装依赖

```bash
cd 智慧医疗项目
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 三、MySQL

### 3.1 基本信息

- 基于 tarball 安装，数据目录 `/opt/mysql/data`，运行用户 `xiaolingyin`
- 配置文件 `/opt/mysql/my.cnf`（socket `/opt/mysql/mysql.sock`，端口 3306）

### 3.2 启动 / 停止

```bash
# 启动
/opt/mysql/support-files/mysql.server start
# 或
/opt/mysql/bin/mysqld_safe --defaults-file=/opt/mysql/my.cnf &

# 停止
/opt/mysql/support-files/mysql.server stop
```

### 3.3 建库

> 本地开发 root 密码已设为**空**（与代码中 `password=""` 保持一致，P2/P3 可直接连接）。

```bash
mysql -u root < 数据库设计/schema.sql
```

## 四、Redis

Redis 7.0.15 由源码编译安装（apt 源只有 6.0.16，不匹配）。

```bash
cd /tmp
wget https://download.redis.io/releases/redis-7.0.15.tar.gz
tar -xzf redis-7.0.15.tar.gz
cd redis-7.0.15
make -j$(nproc)
sudo make install

# 启动
redis-server            # 默认 6379 端口，生产可加配置文件

# 验证
redis-cli ping          # 返回 PONG
```

## 五、Hadoop / Spark / Hive

三者已解压到 `/opt`，关键环境变量在 `/opt/spark/conf/spark-env.sh`：

```bash
export JAVA_HOME=/opt/jdk
export HADOOP_HOME=/opt/hadoop
export HADOOP_CONF_DIR=/opt/hadoop/etc/hadoop
```

### 5.1 启动顺序（分布式任务时）

```bash
start-dfs.sh     # 先启动 HDFS（NameNode 9000、DataNode）
start-yarn.sh    # 再启动 YARN
```

### 5.2 Spark

```bash
spark-submit --version    # Spark 3.5.4
spark-shell               # Scala 交互式
pyspark                   # Python 交互式（需先 source .venv/bin/activate）
```

### 5.3 Hive

```bash
hive --version            # Hive 3.1.3
```

> 注意：`spark-defaults.conf` 里配置了事件日志写 HDFS（`hdfs://localhost:9000`）与 YARN 资源管理，跑 Spark 前需先启动 HDFS/YARN；本地调试可用 `--master local[1] --conf spark.eventLog.enabled=false` 绕过。
