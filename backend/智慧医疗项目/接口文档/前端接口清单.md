# 智慧医疗平台 · 前端接口清单

> 服务地址：`http://127.0.0.1:5000`（已开 CORS，可跨域直连）
> 请求方式：全部 GET；响应统一信封 `{code, message, data, meta}`，`code=0` 成功、`400` 参数错误、`500` 服务错误
> 通用过滤参数（所有接口支持，可叠加）：`year`(仅2021) `gender`(M/F) `age_group` `severity`(1-4 或 Minor/Moderate/Major/Extreme) `payment` `payment2` `payment3` `diagnosis` `procedure` `service_area` `county` `facility`

---

## 一、模块一 · 病种与手术分析（前缀 `/api/v1/disease`）

| 接口 | 主要参数 | 用途 |
| --- | --- | --- |
| `GET /disease/top-diagnoses` | `metric`(count/total_charges/avg_charges/avg_los)、`top`(默认20) | Top 诊断排行，返回 `[{code,name,count,value}]`。用于柱状图（X=name，Y=value）与词云（词=name，权重=count） |
| `GET /disease/top-procedures` | `metric`(count/total_charges/avg_charges)、`top`(默认20) | 手术谱排行，返回 `[{code,name,count,value}]`。用于柱状图（仅统计有手术记录的 150 万条） |
| `GET /disease/severity-profile` | `by`(age_group/medical_surgical/payment)、`metric`(count/avg_charges) | 病重趋势：分组 × 严重程度构成，返回 `[{group,severity,value,count}]`。用于堆叠柱状图（X=group，系列=severity） |
| `GET /disease/population-diff` | `dimension`(gender/race/medical_surgical)、`metric`(count/avg_charges/avg_los) | 人群差异统计，返回 `[{key,count,pct,value}]`。用于分组柱状图（标签可显示 pct%） |
| `GET /disease/pyramid` | 无（仅通用过滤） | 人口金字塔：性别 × 年龄段，返回 `[{age_group,male,female,total}]`。male 取负值向左、female 向右 |
| `GET /disease/region-diff` | `level`(service_area/county/facility)、`metric`(count/total_charges/avg_charges)、`top` | 地区差异：服务区域(8)/县(57)/医院(210)，返回 `[{key,count,value}]`。用于柱状图或纽约州地区地图 |
| `GET /disease/heatmap` | `dim1`、`dim2`(diagnosis/procedure/age_group/severity/gender/payment/service_area，两者不可相同)、`metric`、`top`(默认15) | 通用交叉热力图，返回 `[{dim1,dim1_name,dim2,dim2_name,count,value}]`，前端转 `[dim1,dim2,value]` 三元组直接喂 ECharts heatmap |

## 二、模块二 · 支付分析（前缀 `/api/v1/payment`）

| 接口 | 主要参数 | 用途 |
| --- | --- | --- |
| `GET /payment/composition` | `group`(payment1/payment2/payment3)、`metric`(count/total_charges) | 支付方式构成，返回 `[{key,count,pct,value}]`。用于饼图（扇区=key，数值=pct%） |
| `GET /payment/cross` | `dim2`(age_group/diagnosis/severity)、`metric`(count/total_charges)、`top` | 支付方式 × 年龄段/病种/严重程度交叉，返回 `[{key,dim2,dim2_name,count,value}]`。用于堆叠柱状图（X=支付方式，系列=dim2）或热力图 |
| `GET /payment/sankey` | `levels`(payment,payment2 / payment,payment2,payment3 / payment,age_group / payment,age_group,disease / payment,disease / payment,severity)、`top_disease`(默认8) | 支付流转桑葚图，返回 `{nodes:[{name,display,layer,layer_index}], links:[{source,target,value}]}`，结构与 ECharts sankey 完全对应（节点名带层前缀保证全局唯一） |
| `GET /payment/cost-relation` | `by`(payment/age_group/diagnosis)、`top`(默认30) | 支付费用关系，返回 `[{key,count,avg_charges,avg_costs,charge_cost_ratio}]`。用于散点图（X=avg_costs，Y=avg_charges，气泡大小=count，颜色=费用成本比） |
| `GET /payment/oop-burden` | `dimension`(disease/age_group/county)、`mode`(selfpay1/any_layer)、`top`(默认15) | 自付负担分析，返回 `[{key,total_count,self_pay_count,self_pay_pct,…}]`（mode=selfpay1 时含自付金额字段）。用于柱状图（Y=self_pay_pct）或散点图 |
| `GET /payment/summary` | 无（仅通用过滤） | KPI 总览大屏：总记录数、总费用、总成本、次均费用、次均成本、平均住院天数、自付人数及占比、第一支付方式、严重程度分布、急诊数 |

## 三、公共 · 维度字典（前缀 `/api/v1/meta`）

| 接口 | 主要参数 | 用途 |
| --- | --- | --- |
| `GET /meta/dimensions` | 无 | 一次性返回所有维度枚举：诊断 477 项、手术 320 项（code↔名称映射）、支付方式 9 类、严重程度 4 级、年龄段 5 档、服务区域 8 区、县 57 个。前端所有筛选器下拉框与名称映射从这里取（缓存 24 小时） |

## 四、模块四 · 医疗质量监测（前缀 `/api/v1/quality`）

> 口径：住院死亡率 = 离院去向含 `Expired`；非医嘱离院(AMA) = 含 `Left Against Medical Advice`；转院 = 短期综合医院/联邦机构/乡村急救医院；低出生体重 = `<2500g`（仅新生儿，分母为有出生体重记录）。再入院率、院内感染率因数据无患者唯一标识/无感染字段，本平台不提供。

| 接口 | 主要参数 | 用途 |
| --- | --- | --- |
| `GET /quality/overview` | 无（仅通用过滤） | 质量总览 KPI：总出院数、死亡率、平均住院日、急诊入院率、非医嘱离院率、转院率、低出生体重率、次均费用/成本。用于大屏首页卡片 |
| `GET /quality/mortality` | `dimension`(diagnosis/facility/age_group/severity/risk_mortality)、`top`(默认20)、`min_cases`(默认30) | 死亡率分组排行，返回 `[{key,name,count,deaths,mortality_rate}]`。dimension=risk_mortality 即按预期死亡风险分层的观察死亡率（风险调整对照）。用于柱状图 |
| `GET /quality/length-of-stay` | `dimension`(同 mortality)、`top`(默认20)、`min_cases`(默认30) | 平均住院日排行，返回 `[{key,name,count,avg_los,avg_charges,avg_costs}]`。用于柱状图（X=name，Y=avg_los） |
| `GET /quality/facility-ranking` | `top`(默认15)、`min_cases`(默认100) | 医院质量横向对比，返回 `[{key,name,county,count,mortality_rate,avg_los,ed_rate,ama_rate,transfer_rate,newborns,lbw_rate,avg_charges,avg_costs}]`。用于表格/雷达图 |
| `GET /quality/disposition` | 无（仅通用过滤） | 离院去向构成，返回 `[{key,count,pct}]`（Home/Expired/AMA/转院/Hospice/SNF/Other，固定业务顺序）。用于饼图 |
