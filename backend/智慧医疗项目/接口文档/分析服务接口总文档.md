## 一、服务拓扑

| 服务 | 技术栈 | 端口 | 数据库 | 已实现接口数 | 详细文档 |
| --- | --- | --- | --- | --- | --- |
| 主服务（app.py） | Flask + PyMySQL | 5000 | `smart_health`（192.168.111.141:3306）；emergency 模块连 `medical_db` | 33 | 《病种手术与支付分析接口文档》《医疗质量监测接口文档》《RESTful_API接口文档》《骆志远-急诊与住院分析模块接口文档》 |
| 核心分析（modules/core） | FastAPI | 8000 | `medical_db`（DATA_SOURCE 可切 mysql/hive） | 18 | modules/core/API文档.md |
| DRG 分析（modules/drg） | FastAPI | 8001 | `medical_db` | 17 | modules/drg/API文档.md |

**统一响应信封**（所有服务一致）：

```json
{ "code": 0, "message": "success", "data": { ... }, "meta": { "dimension": "...", "metric": "...", "total_records": 2100000, "filters": {}, "cached": false, "query_ms": 128, "generated_at": "..." } }
```

| 约定 | 说明 |
| --- | --- |
| 错误码 | `0` 成功；`400` 参数错误；`404` 资源不存在；`408` 查询超时；`429` 请求频繁；`500` 服务内部错误 |
| 通用过滤参数（12 种） | `year`（仅2021）`gender`(M/F) `age_group` `severity`(1-4 或 Minor/Moderate/Major/Extreme) `payment` `payment2` `payment3` `diagnosis` `procedure` `service_area` `county` `facility`——主服务所有接口支持、可叠加 |
| 缓存 | 主服务进程内 TTL 缓存 1 小时（命中 `meta.cached=true`、`query_ms=0`）；`/meta/dimensions` 缓存 24 小时 |
| CORS | 已开 `*`，前端可跨域直连 |

## 二、已实现接口清单（63 个）

### 2.1 主服务 `http://127.0.0.1:5000` — 28 个

#### 2.1.1 遗留接口（P4 AI 模块兼容契约，路径不可变）

| 接口 | 说明 | 主要参数 |
| --- | --- | --- |
| `GET /api/v1/health` | 健康检查（含 DB 连通状态） | 无 |
| `GET /api/v1/analysis/aggregate` | 通用聚合分析（核心接口） | `dimension`(age_group/gender/discharge_year/ccsr_diagnosis/facility/payment_typology/severity/aprg_drg)、`metric`(count/avg_length_of_stay/total_charges/avg_charges/total_costs/avg_costs)、`top`(≤100)、`year`、`gender` |
| `GET /api/v1/analysis/payment-mix` | 支付方式占比 | 无 |
| `GET /api/v1/analysis/trend` | 疾病趋势（时间序列） | `diagnosis`(ccsr_code) |

#### 2.1.2 模块一 · 病种与手术分析 `/api/v1/disease/`（7 个）

| 接口 | 说明 | 主要参数 |
| --- | --- | --- |
| `GET /disease/top-diagnoses` | Top 诊断排行（柱状图/词云） | `metric`(count/total_charges/avg_charges/avg_los)、`top` |
| `GET /disease/top-procedures` | 手术谱排行 | `metric`、`top` |
| `GET /disease/severity-profile` | 病重趋势（分组×严重程度堆叠图） | `by`(age_group/medical_surgical/payment)、`metric` |
| `GET /disease/population-diff` | 人群差异统计 | `dimension`(gender/race/medical_surgical)、`metric` |
| `GET /disease/pyramid` | 人口金字塔（性别×年龄段） | 仅通用过滤 |
| `GET /disease/region-diff` | 地区差异（服务区域/县/医院） | `level`(service_area/county/facility)、`metric`、`top` |
| `GET /disease/heatmap` | 通用交叉热力图（ECharts 三元组） | `dim1`、`dim2`(不可相同)、`metric`、`top` |

### 3.1 文档曾声明、代码从未实现的接口（5 个）

> 来源：《RESTful_API接口文档.md》。均为早期契约声明，后由能力更强的模块化接口替代，**均已有替代方案，不建议再实现**。

| 未实现接口 | 规划用途 | 现行替代 |
| --- | --- | --- |
| `GET /api/v1/analysis/length-of-stay` | 平均住院时长分析 | `GET /api/v1/quality/length-of-stay`（同维度排行 + 费用/成本） |
